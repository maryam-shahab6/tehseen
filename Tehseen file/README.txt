# Psychopath's 19th Birthday 🎂🐱

A private, single-page animated birthday surprise.

## Files
- `index.html` — all scenes and birthday letter
- `style.css` — design and animations
- `script.js` — interactions and confetti
- `assets/` — optional place for future cat artwork/sounds

## Run it
Double-click `index.html` to open it in your browser.

## Put it online with Netlify
1. Go to Netlify.
2. Choose to add/deploy a new project.
3. Drag the entire `sekoueth-birthday` folder into the upload area.
4. Netlify will give you a shareable `.netlify.app` link.

No Supabase or database is required.
